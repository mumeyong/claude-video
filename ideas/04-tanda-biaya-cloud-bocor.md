# 5 tanda biaya cloud kamu bocor

## Takeaway (1 kalimat)
Kalau kamu nemu satu aja dari 5 tanda ini, tagihan cloud-mu bisa dipotong.

## Bab (checklist)
1. VM nyala 24 jam padahal dipakai jam kerja doang
2. Disk & IP yang nggak nempel ke apa-apa
3. Snapshot / backup numpuk bertahun-tahun
4. Instance kegedean (CPU rata-rata < 20%)
5. Nggak ada tag → nggak tahu siapa yang bayar apa

## Bukti / visual
Checklist yang dicentang satu-satu (chime), counter "bocor" naik

Pemetaan ruangan → tanda:
- 💡 kamar kosong lampu nyala = VM nganggur 24 jam
- 🚰 keran netes = disk yang nggak nempel ke mana-mana
- 📦 gudang numpuk = snapshot bertahun-tahun
- ❄️ AC kegedean buat kamar kecil = instance kebesaran
- 🧾 meteran tanpa nama = resource tanpa tag

Sentuhan manusia:
- **Artefak asli:** satu angka nyata yang dianonimkan (mis. "pernah nemu ratusan snapshot") — tanya user
- **Opini:** "tag itu bukan formalitas — tanpa tag kamu nggak tahu siapa yang bayar apa"
- **Kejutan:** di akhir kamera mundur — rumahnya ternyata satu dari puluhan rumah (satu akun dari banyak project)
- **Ketidaksempurnaan:** garis rumah digambar kayak sketsa tangan (stroke sedikit goyang)
