# LESSONS — read before every video; add one line after every review round (what was wrong → the rule)

- Wide objects against the right edge overflow → compute it: `x + w <= X + CW - 40`. Roofs/awnings stick out 4–8 %.
- Spreading effects (rings, particles) leave the column → point them into the frame, cap their radius.
- Never invent a number or claim; anonymise client AND project names ("Customer 360" → "Project 360").
- Getting repetitive: giant punch word in every intro, dark recap + serif closing word every time, headline → hero →
  tags at y ≈ 1280 in every chapter. Vary them.
- Motion read as "AI slop" when every rule ADDED motion → stillness, one leader, holds (STYLE §5).
- Pango wrapped text collapses under a scaled canvas → wrap once in design units, draw line by line (`obrolan.py`).
