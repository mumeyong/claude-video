# Kamu ngetik prompt — sebenernya diproses di mana? — format QUICK

> Ide #16 · pilar B (AI sehari-hari) · target 60–75 s (≈ 175 kata) · lihat ideas/STRATEGY.md
> Satu hero object yang berubah tiap bab: **studio radio "ON AIR"** (lampu ON AIR + mic + paku nota request) —
> prompt kamu = kertas request yang dikirim ke studio di seberang laut (data center), antre di meja penyiar (GPU),
> lalu jawabannya *disiarkan langsung* balik ke HP kamu, token demi token (streaming).
> Satu hal yang cuma Mumeyong bisa bilang: pengalaman bangun infra GPU (EP07) — "nggak ada yang mau GPU-nya idle
> sedetik pun", makanya kamu antre.
> Fakta: chatbot kayak ChatGPT jalan di data center (model terlalu besar buat HP), trafik internasional lewat kabel
> bawah laut, request antre ke GPU yang dipakai bareng, jawaban di-generate token demi token dan dikirim sambil jalan
> (streaming). Nggak ada angka spesifik di layar. "Biasanya di luar negeri" = ⚠️ cek (lokasi data center beda-beda).
> Anti-slop: tanpa "Di era digital", "Tahukah kamu", "Yuk simak". Tech terms English (GLOSSARY.md):
> enter, prompt, WiFi, data center, model, GPU, request, idle, server, token, streaming.
> Read-aloud marks: *kata* = tekanan, ' //' = napas.
>
> HOOK — A/B/C (A terpasang):
> A · Cold open di tengah aksi: "Kamu tekan enter. Belum sedetik, kalimatmu udah nyebrang laut."
> B · Radio: "Ngetik prompt ke AI itu mirip banget kayak request lagu ke radio."
> C · Kebalik: "Tulisan AI yang muncul pelan-pelan itu bukan efek. Dia beneran baru dibikin."
> (3 video terakhir: eksperimen + klaim, kuis ke penonton, before/after → A dipasang.)

## INTRO
[L01] Kamu tekan *enter*. Belum sedetik, kalimatmu udah *nyebrang laut*. //
[L02] Soalnya yang mikirin jawabannya bukan *HP* kamu. //
[L03] Anggap aja kamu lagi kirim request ke *radio*.

## 00 · BERANGKAT
[L04] Prompt kamu jalan lewat WiFi atau sinyal, terus masuk *kabel bawah laut*.
[L05] Tujuannya *data center*, biasanya di luar negeri. Itu studionya. //
[L06] Di sana tinggal *model* AI-nya, yang terlalu gede buat muat di HP. //

## 01 · ANTRE
[L07] Di studio, request kamu nggak sendirian. Ada *ribuan* yang masuk barengan.
[L08] Penyiarnya itu *GPU*. Mahal banget, jadi jumlahnya terbatas. //
[L09] Aku pernah bangun infra GPU. Nggak ada yang mau GPU-nya *idle* sedetik pun.
[L10] Makanya pas lagi rame, muncul tulisan *server sibuk*. Itu antrean, bukan HP kamu yang lemot. //

## 02 · SIARAN LANGSUNG
[L11] Giliran kamu: lampu *on air* nyala.
[L12] Dia nebak satu *token*, satu potongan kata, terus nebak lagi.
[L13] Tiap token yang jadi, langsung *disiarin* balik ke HP kamu. //
[L14] Itu namanya *streaming*. Tulisan yang muncul pelan-pelan itu bukan efek. Dia emang *baru* dibikin. //

## RECAP
[L15] Jadi satu prompt itu nyebrang laut, antre, terus disiarin balik, semua dalam *beberapa detik*.

## OUTRO
[L16] Follow, berikutnya: AI yang *beneran* jalan di dalam HP kamu.
