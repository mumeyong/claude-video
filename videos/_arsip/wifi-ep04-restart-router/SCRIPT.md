# Restart router beneran ngefek? — format QUICK · Bongkar WiFi Rumah EP 04

> Pilar: B (broad) · target 60–75 s (≈ 185 kata) · seri **Bongkar WiFi Rumah** (ideas/14, ideas/22) · lihat ideas/STRATEGY.md
> Ide: [ideas/22-wifi-ep04-restart-router.md](../../ideas/22-wifi-ep04-restart-router.md)
> Hero: **buku tamu satpam** (router = pos satpam dari EP 02). Tiap koneksi dicatat satu baris; halaman habis → tamu baru
> disuruh nunggu; restart = halamannya disobek, buku bersih. Signature: baris-baris keisi cepat → halaman disobek → kertas bersih.
> Satu hal yang cuma Mumeyong bisa bilang: pengakuan orang infra — server production juga "sembuh" abis di-restart, dan
> kalau harus rutin, itu gejala, bukan obat (L20–L21).
> Fakta (aman, umum, tanpa angka): router rumah nyatet tiap koneksi di NAT table (connection tracking) — kapasitasnya
> terbatas; kalau penuh, koneksi baru telat/gagal. Firmware bisa bocor memory kalau nyala lama. Restart ngosongin dua-duanya.
> Restart nggak nyentuh masalah di luar router: kabel putus / LOS (EP 01), gangguan di sisi ISP (EP 02), sambungan basah (EP 03).
> Bahasa: "bisa", bukan "pasti". Nggak ada angka (berapa baris, berapa detik nunggu, berapa hari). ISP nggak disebut merek.
> Anti-slop: tanpa "Di era digital", "Tahukah kamu", "Yuk simak". Tech terms English (GLOSSARY.md): restart, router,
> NAT table, memory, firmware, update, ISP, production, server, LOS.
> Read-aloud marks: *kata* = tekanan, ' //' = napas. NAT dibaca "nat", ISP "i-es-pe", LOS "el-o-es" (audio/tts_lexicon.txt).
>
> HOOK — A/B/C (A terpasang):
> A · Kutipan sehari-hari: "Udah dicoba restart, Kak?" — "Kadang beneran sembuh. Kadang cuma buang waktu. Bedanya ada di satu buku."
> B · Jam pasir: modem nyala ulang — "Tiga menit ini sebenernya ngapain?"
> C · Klaim: "Restart router itu nyobek buku tamu satpam."

## INTRO
[L01] "Udah dicoba *restart*, Kak?" //
[L02] Kadang beneran *sembuh*. Kadang cuma buang waktu.
[L03] Bedanya ada di satu buku *tamu*. //

## 00 · BUKU TAMU
[L04] Router kamu itu kayak satpam yang *nyatet* tiap tamu.
[L05] Tiap app yang konek ke internet, dapet satu *baris*.
[L06] Namanya *NAT table*. Dan halamannya terbatas. //
[L07] Nyala berminggu-minggu, bukunya *penuh*. Memory-nya juga sesak.
[L08] Tamu baru disuruh *nunggu*. Itu lemot yang kamu rasain.
[L09] Restart itu nyobek semua halamannya. Buku *bersih* lagi. //

## 01 · KAPAN PERCUMA
[L10] Tapi restart cuma ngurus yang ada di *dalam* router.
[L11] Lampu LOS merah? Kabelnya *putus*. Episode satu.
[L12] Gangguan dari ISP? Palangnya di *luar*. Episode dua.
[L13] Sambungan basah kena hujan? Episode *tiga*.
[L14] Bukunya diganti berkali-kali, jalannya tetap *rusak*. //

## 02 · YANG BISA KAMU LAKUIN
[L15] Restart *sekali*. Cabut, tunggu sebentar, colok lagi.
[L16] Langsung lancar? Berarti bukunya yang *penuh*.
[L17] Tapi kalau harus restart *tiap* hari, router-nya kewalahan.
[L18] Cek update *firmware*-nya, atau minta ISP ganti modem. //

## RECAP
[L19] Di kerjaan, server production juga sering sembuh abis di-*restart*.
[L20] Tapi kalau harus restart rutin, itu bukan obat. Itu *gejala*. //
